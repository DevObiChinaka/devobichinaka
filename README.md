## Selected Projects

### [Oxiworld / Oxidane](https://github.com/DevObiChinaka/oxidane)
A SaaS learning platform project exploring subscription-based access, payment integration, authentication, and connected services.

**Technologies:** Django, Next.js, TypeScript, PostgreSQL, Redis, Celery

### [UniApp](https://github.com/DevObiChinaka/uniapp)
A university attendance-management project combining a web backend and mobile application, with features including QR-based attendance, geolocation checks, and facial-recognition integration.

**Technologies:** Django, Python, Flutter, Dart, PostgreSQL, Firebase

### [Darew Ventures](https://github.com/DevObiChinaka/darew)
A corporate website project focused on presenting company services and business information.

**Technologies:** Next.js, React, TypeScript, Tailwind CSS  
**Live site:** [darew.netlify.app](https://darew.netlify.app/)

### [ADUN Dinner & Awards Night Ticketing](https://github.com/DevObiChinaka/dinner)
A lightweight event-ticketing project using QR codes to support ticket verification and attendance tracking.

**Technologies:** HTML, CSS, JavaScript  
**Live demo:** [devobichinaka.github.io/dinner](https://devobichinaka.github.io/dinner/)

### Final-year project: ScoreCode
My final-year project involved the design and development of **ScoreCode**, a computer-based programming examination and automated code-evaluation system. It explored candidate management, server-side exam controls, code submission, and automated evaluation.
