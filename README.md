## Featured Projects

### [Oxiworld - SaaS Learning Platform](https://github.com/DevObiChinaka/oxidane)
Production SaaS platform with subscription management, payment integration (Paystack), Google OAuth, and Telegram bot integration. Features multi-layer subscription protection and automated renewals.

**Tech Stack:** Django • Next.js • TypeScript • PostgreSQL • Redis • Celery • Gunicorn • Nginx  
**Live Demo:** [oxidane-two.vercel.app](https://oxidane-two.vercel.app/)

---

### [UniApp - Smart Attendance System](https://github.com/DevObiChinaka/uniapp)
Advanced full-stack attendance management platform with Flutter mobile app featuring AI-powered facial recognition, geolocation fencing, and QR code scanning. Django backend with admin dashboard and security monitoring.

**Tech Stack:** Django • Python • Flutter • Dart • PostgreSQL • Firebase • ML Kit • REST API  
**Highlights:** AI facial recognition • Geofencing • Real-time tracking

---

### [Darew Ventures - Oil & Gas Corporate Website](https://github.com/DevObiChinaka/darew)
Comprehensive corporate website for Nigeria's leading indigenous oilfield service company with 30+ years of industry experience. Features service showcases and business information architecture.

**Tech Stack:** Next.js • React • Tailwind CSS • TypeScript  
**Live Demo:** [darew.netlify.app](https://darew.netlify.app/)

---

### [ADUN Dinner & Awards Night Ticketing](https://github.com/DevObiChinaka/dinner)
QR code-based ticketing system for university annual dinner and awards event. Generates unique QR tickets with real-time validation and attendance tracking.

**Tech Stack:** HTML • CSS • JavaScript • QR Code API
